# AgriTrace Platform Architecture

AgriTrace tracks agricultural products through their complete lifecycle:

`Farmer` -> `Harvest` -> `Batch Creation` -> `Quality Inspection` -> `Warehouse` -> `Transportation` -> `Retailer` -> `Customer` -> `QR Verification`

## Tech Stack
- **Backend**: FastAPI, SQLAlchemy, PostgreSQL, Pydantic v2, PyJWT, Bcrypt
- **Frontend**: React 18, TypeScript, Vite, React Router, Custom CSS Theme
- **Infrastructure**: Docker, Docker Compose
